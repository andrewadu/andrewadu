## How I work

I stay close to the system after the architecture diagram is done: designing the data model, building critical paths, reviewing frontend workflows, deploying services, instrumenting production, and responding when real-world behaviour differs from the plan.

AI is part of that engineering workflow—not a substitute for judgment. I use Codex, Claude Code, MCP workflows, and agentic tools to accelerate research, implementation, testing, and operations while keeping human review, security, and evidence in the loop.
